# 為什麼美國公債殖利率會影響台股

> 一句話：**台股的「盈餘」由台灣公司決定，但台股的「本益比」由美國利率決定。**

```
股價  =  EPS  ×  本益比
          ↑        ↑
        引擎      煞車
      AI 需求   美債殖利率
```

這就是為什麼一個在紐約交易的數字，會決定台北的指數。

## 現在的水位

| | |
|---|---|
| 10 年期公債殖利率（9/17） | **4.95%** |
| 本週稍早高點 | **5.04%** — **2007 年以來最高** |
| 聯邦基金利率目標區間 | 3.75%–4.00%（9/16 升息 1 碼） |

上一次 10 年期殖利率站上 5%，是**金融海嘯之前**。

## 四條傳導路徑

### 一、折現率：這是數學，不是情緒

股票的價值 = 未來所有獲利的**現值**。而現值的算法是：

```
現值 = 未來的錢 ÷ (1 + 折現率)^年數
```

折現率的地基，就是無風險利率——也就是 10 年期公債殖利率。

**一筆 10 年後的 100 元，今天值多少？**

| 折現率 | 現值 | |
|---|---|---|
| 4% | 67.6 元 | |
| 5% | 61.4 元 | **少 9.1%** |

**如果是 20 年後的 100 元：**

| 折現率 | 現值 | |
|---|---|---|
| 4% | 45.6 元 | |
| 5% | 37.7 元 | **少 17.4%** |

**年數越遠，殺傷力越大**——因為分母是次方。

這推出一個關鍵結論：**折現率上升對「成長股」的傷害遠大於「價值股」**，
因為成長股的價值大部分押在很遠的未來。

**台股權值 = AI 半導體 = 成長股 = 對殖利率最敏感的那一類。**
這就是為什麼台股比許多市場更吃這一套。

### 二、機會成本：資金的比價

無風險的美國公債給你 **4.95%**，那為什麼要冒險買股票？

股票必須提供足夠的**風險溢酬**才值得持有。公債殖利率越高，
股票就必須越便宜（本益比越低）才划算。

這對台股特別直接，因為**外資**。外資持有台股市值的比重長期在四成上下，
而他們的資金成本是美元利率，不是台幣利率。他們隨時可以選：

- 買美債，無風險拿 4.95%
- 或買台股，同時承擔股價風險 + 匯率風險

殖利率越高，第二個選項就越難說服人。

### 三、匯率：外資賣超為什麼和殖利率同步

```
美債殖利率上升 → 美元資產更有吸引力 → 資金回流美元
→ 美元升值、新台幣貶值 → 外資持有台股產生匯損 → 賣台股換美元
```

這解釋了 9/16 那天出現的組合：**美債殖利率走升 + 美元升值 + 股市下跌**。
那不是三件事，是同一件事的三個面向。

### 四、企業實際成本（影響最小）

利率高 → 借錢成本上升 → 資本支出縮手、利息費用侵蝕獲利。

但這條對台股反而影響最小：台積電現金滿手，AI 資本支出是戰略性投資，
不太會因為利率而縮手。

## 為什麼是「美國」的利率，不是台灣央行的？

1. **台股約八成成交量是電子股，而電子股整個活在美元體系裡** —
   台積電營收以美元計價，主要客戶是美國雲端巨頭
2. **外資持有台股市值約四成**，他們的資金成本是美元利率
3. **台股的估值是「跟美股比價」比出來的** — 費半漲 3.14%，台積電就跟

台灣央行的利率對台股本益比的影響反而小得多，因為**決定台股估值的那筆錢不是台幣**。

## 用這三週的實際行情驗證

| 區間 | 發生什麼 | EPS 變了嗎 | 本益比 |
|---|---|---|---|
| 9/8–9/15 | **-1,815 點** | 沒有。AI 需求沒消失 | 被殖利率（→5.04%）壓下去 |
| 9/16–9/18 | 連續反彈 | 沒有 | 殖利率回落到 4.95%，彈回來 |

**這三週台股的漲跌，幾乎沒有一次是因為「台灣公司賺得更多或更少」。
全部是本益比在動。**

## 所以該盯什麼

不用每天看台股漲跌，盯那個數字就好：

| 10 年期殖利率 | 意義 |
|---|---|
| 往 **5% 以上** | 本益比壓縮，台股估值承壓 |
| 往 **4.5% 以下** | 壓力解除，引擎（AI 盈餘）才發揮得出來 |

目前 4.95%，且 Fed 點陣圖顯示 18 位官員中 16 位預計**還會再升息**。
煞車可能還會再踩。
