## 異常門檻

- 加權指數單日或盤中 **±1.5%** 以上
- 任一持股 **±5%** 以上，或亮燈漲停 / 跌停
- 盤中方向反轉且振幅 ≥ 1.5%（僅 12:18 那一支）
- 重大突發事件（個股重訊、地緣政治、央行動作、停牌）

## 報告的核心設計：成因必須分類

每份盤後報告都會把漲跌原因歸到四類其中之一，這是整套系統最重要的部分：

1. **基本面題材** — 訂單、財報、新產品、產業循環
2. **資金與籌碼面** — 外資動向、ETF 調整、融資券
3. **技術性因素** — MSCI/FTSE 指數調整、期貨結算、除權息、作帳行情
4. **國際連動** — 美股、費半、匯率、地緣政治

第 3 類特別會被標註出來，因為那種漲跌**不代表基本面改變，通常不會延續**。
2026/08/31 尾盤爆量 3,000 億就是典型例子——那天的下跌純粹是 MSCI 季調換手。

## 待補：持股清單

四支排程的 prompt 裡目前都寫著「（尚未提供）」。補上持股代號後，
盤後報告才能逐檔追蹤，異常偵測才能真的盯到你的部位。

格式範例：

```
2330 台積電
2454 聯發科
2379 瑞昱
00尾數 ETF 也可以
```

更新方式：直接跟 Claude 說持股清單，會用 `update_trigger` 寫進四支排程，
不需要刪掉重建（刪掉會失去執行紀錄）。

## 限制（請務必知道）

- **沒有券商 API 串接。** 系統看不到你的實際庫存、成本、損益，
  只能追蹤你告訴它的股票代號的公開漲跌幅。
- **不是即時監控。** 排程是固定時間點檢查，不是持續盯盤。
  盤中若在 10:33 與 12:18 之間發生急殺，要到下一個檢查點才會發現。
- **資料來源是公開新聞搜尋**，不是交易所直連。數字可能落後或有出入，
  重要決策請以券商 App 或交易所公告為準。
- **不提供買賣建議。** 所有報告只解釋成因、只列觀察點。

## 常用指令

- 查看所有排程：跟 Claude 說「列出我的 routines」
- 暫停某支：「把盤中異常偵測停掉」
- 改時間或門檻：「盤後報告改成 13:45」「異常門檻改成 2%」
- 臨時跑一次：「現在幫我跑一次盤後分析」
